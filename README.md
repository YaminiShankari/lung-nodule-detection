# 🫁 Lung Nodule Detection AI

An intelligent Lung Nodule Detection system powered by Deep Learning (ResNet18) and Machine Learning (Logistic Regression) for accurate classification of CT scan images.

The system analyzes lung CT scans, extracts high-level features using a pretrained CNN, and predicts whether a scan is Cancerous or Non-Cancerous, along with a confidence score. This project integrates computer vision, deep learning, and full-stack development to assist in early-stage lung cancer detection.

# 📂 Project Files Overview
# 🔹 Backend (backend/)

1️⃣ app.py

Built using Flask to handle API requests.

Accepts CT scan images via /predict endpoint.

Uses ResNet18 as a feature extractor.

Loads a trained Logistic Regression model (.pkl) for classification.

Returns prediction results along with confidence score in JSON format.

Acts as the bridge between frontend and AI model.

2️⃣ lung_cancer_model.pkl

The trained machine learning model 📊

A Logistic Regression classifier trained on extracted image features.

Predicts whether a scan is Cancerous or Non-Cancerous.

Works on top of features generated by ResNet18.


3️⃣ requirements.txt

Contains all Python dependencies required to run the backend.

Includes libraries such as Flask, NumPy, OpenCV, PyTorch, and scikit-learn.

# 🔹 Frontend (frontend/)

4️⃣ App.jsx

The user’s diagnostic interface 🎨

Built using React (Vite).

Allows users to upload CT scan images via drag & drop or file selection.

Sends images to backend using API calls (fetch).

Displays:

Prediction result (Cancer / No Cancer)

Confidence score

Provides a clean and responsive UI for smooth user interaction.

5️⃣ App.css / index.css

Defines the UI styling and layout.

Implements a modern medical dashboard design with clean spacing and visual hierarchy.


# ⚙️ Installation & Setup
To set up and run the project locally:

1️⃣ Clone the repository

git clone https://github.com/YaminiShankari/lung-nodule-detection.git

cd lung-nodule-detection

2️⃣ Setup Backend

cd backend

pip install -r requirements.txt

python app.py

3️⃣ Setup Frontend

cd frontend

npm install

npm run dev

✅ Requirements

Python ≥ 3.9

Node.js ≥ 16

pip & npm installed

⚠️ Make sure the backend server is running before starting the frontend.
